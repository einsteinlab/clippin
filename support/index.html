About ClipPin

ClipPin is a minimal macOS menu bar app for saving and copying frequently used plain text snippets. It is designed for local, offline use.

Basic Usage

  1. Open ClipPin from the macOS menu bar.
  2. Choose Add New Snippet to save a plain text snippet.
  3. Select a saved snippet from the menu to copy it to the clipboard.
  4. Use Delete Snippet to remove a specific saved item.

Plain Text Only

ClipPin is intended for plain text snippets. It does not save rich text formatting, images, or attachments.

Privacy

ClipPin does not collect data, does not require an account, does not use cloud sync, and does not access the network. Text snippets stay on your Mac.

Troubleshooting

  • If a copied snippet does not appear where expected, try pasting into a plain text editor first.
  • If ClipPin is not visible, check the macOS menu bar area and make sure the app is running.
  • If you need to remove old content, use the delete menu to remove individual snippets.
